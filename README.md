# Oltre la Soglia

Oltre la Soglia is the website of my reading group.

It is dedicated to the exploration of weird fiction, horror, science fiction, and dark fantasy, with a focus on reading, discussion, and creative atmosphere.

This project is a personal and non-commercial website created for the purpose of sharing the group's reading activity and related content. It is not intended for commercial use, profit, resale, or reuse in other contexts.
